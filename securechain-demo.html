SECURECHAIN
Features How it works
⛓ Demo Mode · Simulation Environment
Blockchain-secured asset &
identity management
SecureChain gives owners cryptographic control over every protected operation — while managers work fast and every action is verified, approved, and permanently recorded.
Runs entirely in your browser · No real credentials, blockchain, or backend required.
Role-Based Access
Owner, Admin/Manager, and Employee roles each see exactly what they're permitted to — enforced in code, not just hidden UI.
Owner Approval Workflow
Managers submit requests for protected operations; nothing executes until the Owner reviews and approves it.
Blockchain-Verified Records
Every executed action is written to a simulated ledger with a transaction ID, block number, and confirmation status.
Digital Identity (DID)
Every user holds a decentralized identifier anchored to a wallet address instead of a central authority.
Full Audit Trail
Every login, request, approval, rejection, and edit is logged chronologically for complete traceability.
Owner Asset & User Registry
Owners register employees and assets directly, then grant time-limited edit permissions to admins on request.
Security Center
Live control status and an interactive test that demonstrates a blocked unauthorized action in real time.
Live Dashboard
Real-time counts of users, assets, pending approvals, and blockchain records tailored to each role.
How a protected operation gets executed
Manager/Admin requests a protected operation (transfer, freeze, update, or edit access).
Request enters Pending Owner Approval — it cannot be executed directly.
Owner reviews, then approves or rejects.
System executes the action, writes an audit log, and records a simulated blockchain transaction.
SecureChain DEMO MODE — simulation environment. The real system (FastAPI, PostgreSQL, Redis, Solidity/Hardhat) lives in the project repository.
